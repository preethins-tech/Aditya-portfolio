# Shahid Portfolio - HTML Version

A modern, responsive portfolio website built with pure HTML, CSS, and JavaScript. Features separate pages for About, Experience, Projects, and Contact sections.

## 🌟 Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern UI**: Clean and professional design with smooth animations
- **Multi-Page Navigation**: Separate HTML files for each section
- **Interactive Elements**: Dynamic contact form, hover effects, and animations
- **Pure HTML/CSS/JS**: No dependencies required
- **GitHub Pages Ready**: Can be easily hosted on GitHub Pages

## 🚀 Live Demo

You can access this portfolio at: [https://ashahid004-ops.github.io/shahid-portfolio/](https://ashahid004-ops.github.io/shahid-portfolio/)

## 🏃‍♂️ Running Locally

1. **Download the files**
   - Clone or download all HTML files to a folder
   - Ensure all files are in the same directory

2. **Open in browser**
   - Double-click `index.html` to open in your default browser
   - Or right-click and choose "Open with" your preferred browser

3. **Use a local server (recommended)**
   ```bash
   # If you have Python installed
   python -m http.server 8000
   
   # If you have Node.js installed
   npx serve .
   
   # Then open http://localhost:8000
   ```

## 🚀 Deployment Options

### GitHub Pages
1. Create a new repository on GitHub
2. Upload all files to the repository
3. Go to Settings > Pages
4. Select "Deploy from a branch" and choose main/master
5. Your site will be available at `https://yourusername.github.io/repository-name`

### Netlify
1. Zip all the HTML files
2. Go to [netlify.com](https://netlify.com)
3. Drag and drop the zip file or folder
4. Your site will be deployed instantly

### Vercel
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` in your project folder
3. Follow the prompts

## 🎨 Customization

### Updating Personal Information

**Navigation**: 
- Logo text is in each HTML file's header section

**Content**:
- **Home**: Edit `index.html`
- **About**: Edit `about.html` 
- **Experience**: Edit `experience.html`
- **Projects**: Edit `projects.html`
- **Contact**: Edit `contact.html`

**Styling**:
- All styles are in `styles.css`
- Colors, fonts, and layout can be easily customized
- The design uses CSS custom properties for theming

**Functionality**:
- Interactive features are in `script.js`
- Contact form handling, animations, and navigation

### Key Sections to Update

1. **Personal Information**:
   - Update name, title, and bio in `index.html`
   - Update about section in `about.html`
   - Update contact details in `contact.html`

2. **Work Experience**:
   - Edit timeline items in `experience.html`
   - Update job titles, companies, dates, and descriptions

3. **Projects**:
   - Update project cards in `projects.html`
   - Add your own project links and descriptions
   - Update technology tags

4. **Contact Information**:
   - Update email, phone, social media links in `contact.html`
   - Modify the contact form fields as needed
